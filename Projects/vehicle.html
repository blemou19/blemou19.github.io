Contexte & objectif

Ce projet répond à un besoin concret : estimer automatiquement le prix de reprise d'un véhicule d'occasion à partir de ses caractéristiques (marque, modèle, kilométrage, année, carburant).

L'enjeu principal est le feature engineering — il divise le RMSE par plus de 2 (de 5 720 € à 2 612 €) et constitue la contribution clé du projet. Le modèle final est déployé en production via une API REST accessible depuis une interface web sur Google Cloud.

Feature Engineering

L'étape la plus déterminante du projet — elle divise le RMSE par plus de 2.

Les variables catégorielles (marque, carburant, modele) sont encodées par target encoding — chaque catégorie est remplacée par la moyenne des prix observés.

Comparaison des modèles

ModèleRMSE (€)R²TempsDécision
Random Forest ★ 2 612 0.89 44 sec Retenu
LightGBM 2 800 0.87 27 sec Non retenu
MLP (réseau de neurones) > 5 000 < 0.80 102 sec Non retenu

Le Random Forest (150 arbres, profondeur 30) offre le meilleur compromis précision / temps d'entraînement. L'intervalle de confiance à 95% est calculé à partir de la variance entre les arbres (± 1.96 × écart-type).

Évaluation du modèle Random Forest

Graphiques d'évaluation du modèle Random Forest retenu : distribution des résidus, valeurs prédites vs réelles, et importance des variables. Le R² de 0.89 confirme la bonne capacité prédictive du modèle.

Comparaison Random Forest vs LightGBM

Comparaison des performances entre Random Forest et LightGBM. Malgré un temps d'entraînement plus rapide, LightGBM affiche un RMSE de 2 800 € contre 2 612 € pour le Random Forest — d'où le choix final en faveur du RF.

Interface web & déploiement

Interface web accessible depuis un navigateur. L'utilisateur saisit les caractéristiques du véhicule et obtient instantanément une estimation du prix avec un intervalle de confiance à 95%.

L'API est structurée autour de deux routes principales :

# GET /marques → liste des marques disponibles
# POST /predict → estimation du prix

{
  "marque": "CITROEN",
  "modele": "C4 Picasso 1.6 HDi",
  "annee": 2018,
  "kilometrage": 80000,
  "carburant": "Diesel"
}

# Réponse :
{
  "prix_estime": 12450.00,
  "intervalle": { "bas": 10527, "haut": 14372 }
}
